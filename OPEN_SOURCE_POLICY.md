# Open Source Policy

bluei is commercial open source with a protected public core.

## Public Core Promise

The public bluei core is licensed under **AGPL-3.0-or-later** and is intended to remain open source.

We want bluei to be useful for individuals, teams, and companies that want to self-host it, study it, modify it, and improve it. Existing public releases will remain available under their open-source license.

## Why AGPL

AGPL-3.0-or-later protects the commons around network-hosted software. If someone modifies the AGPL-covered core and provides it to users over a network, the license requires them to make the corresponding modified source available under AGPL terms.

That helps ensure improvements to hosted versions of the core can remain available to users.

## Contributions Back Upstream

We strongly encourage upstream contributions. If you fix a bug, improve a detector, add a language pack, harden a workflow, or make bluei more useful, we would like that improvement to come back to the public project.

We do not require every modification to be submitted as a pull request to the official repository. The legal requirement comes from the license: network-hosted modified versions of the AGPL-covered core must make their corresponding source available under AGPL terms.

## Official Commercial Offerings

The project owner may offer official hosted, managed, commercial, support, enterprise, private-deployment, or dual-licensed versions of bluei.

Those offerings may include community contributions under the project's Contributor License Agreement. The purpose is to make bluei sustainable as both an open-source project and a viable product.

## Brand And Official Status

The code is open source, but the official bluei name, logo, domain, and Waterworks HQ branding are controlled by the project owner. Forks and modified versions must not imply that they are official bluei releases or official Waterworks HQ services unless they have permission.

See `TRADEMARK.md` for the brand-use policy.

## Summary

- The public core is AGPL-3.0-or-later.
- Existing public releases stay open source.
- Self-hosting, personal use, modification, and learning are welcome.
- Upstream contributions are strongly encouraged.
- Official commercial and hosted offerings may exist.
- The official brand is controlled separately from the code license.
