# Trademark And Brand Policy

This policy explains how the bluei name, logo, domain, and related branding may be used.

## Controlled Brand Assets

The project owner controls the official bluei brand, including:

- the `bluei` name,
- the bluei logo and visual identity,
- the `bluei.dev` domain and official web properties,
- Waterworks HQ names, marks, and branding,
- official hosted, managed, support, enterprise, and commercial offerings.

The software code is licensed separately under AGPL-3.0-or-later. The code license does not grant permission to use the official brand in a way that suggests endorsement, sponsorship, or official status.

## Allowed Uses

You may use the bluei name to:

- refer truthfully to the open-source project,
- describe compatibility with bluei,
- link to the official project,
- discuss bluei in articles, talks, tutorials, reviews, or documentation,
- identify that your project is a fork or modified version of bluei.

Examples:

- "Built with bluei"
- "Compatible with bluei"
- "A fork of bluei"
- "Uses the bluei open-source project"

## Uses That Need Permission

You need written permission to:

- present a fork or modified version as the official bluei project,
- use the bluei logo as the primary branding for a separate product or service,
- use Waterworks HQ branding for your product or service,
- register domains, package names, social handles, or company names that imply official bluei status,
- market a hosted service as the official bluei hosted service.

## Forks And Modified Versions

You may fork and modify the code under the open-source license, but your fork must be clearly distinguishable from the official project.

If you distribute or host a modified version, use wording such as "fork of bluei" or "based on bluei" instead of presenting it as official bluei.

## Official Services

Only the project owner or an authorized entity may describe a service as:

- official bluei,
- bluei Cloud,
- bluei Enterprise,
- Waterworks HQ bluei,
- or any similar official hosted, managed, support, or enterprise offering.

## Questions

If you want to use the brand in a way not covered here, ask first.
